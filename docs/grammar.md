# Граматика SIPL

БНФ з практикуму (ПР 1):

```
P ::= begin S end
S ::= x := a | S1 ; S2 | if b then S1 else S2 | while b do S | begin S end | skip
a ::= n | x | a1 + a2 | a1 - a2 | a1 * a2 | (a)
b ::= a1 = a2 | a1 > a2 | b1 ∨ b2 | ¬b | (b)
```

Така БНФ неоднозначна (наприклад, `1 + 2 * 3` або `S1 ; S2 ; S3` можна вивести кількома деревами),
тому в реалізації зафіксовано пріоритети й асоціативність.

| Конструкція | Рішення |
|---|---|
| `;` | найнижчий пріоритет серед операторів, ліва асоціативність |
| тіло `while`, гілки `if` | один оператор без `;` (кілька - у `begin ... end`) |
| `+`, `-` | ліва асоціативність |
| `*` | вищий за `+`, `-`, ліва асоціативність |
| `∨` | найнижчий серед умов, ліва асоціативність |
| `¬` | вищий за `∨`; `¬ X > 1` означає `¬ (X > 1)` |
| `=`, `>` | порівняння виразів, вищі за `¬` та `∨` |

Лексика:
- ключові слова: `begin end if then else while do skip`; для `∨` та `¬` допустимі ASCII-варіанти `or`, `not`;
- змінна: літера або `_`, далі літери, цифри, `_`; не може збігатися з ключовим словом;
- число: цифри; від'ємна константа записується як `-5`, коли `-` стоїть там, де очікується операнд
  (тому `Y - 1` це віднімання, а `Y - -1` віднімання від'ємної константи);
- пробіли й переноси рядків ігноруються.

Дужка в умові може відкривати і умову `(X > 1)`, і вираз `(X + 1) > 2`. Парсер спочатку пробує
розібрати її як умову, а якщо не виходить - як порівняння виразів.

Імена правил у дереві виводу (`P1`, `S1`-`S6`, `A1`-`A6`, `B1`-`B5`, `NV`, `NN`) збігаються з іменами
в таблиці БНФ практикуму. Формальні файли: `grammar/sipl.ebnf`, `grammar/sipl.lark`.
